유타건축 재료 마감 리스트

재료 DB를 한 번 세팅해두면, 모든 프로젝트에서 재사용할 수 있어요.
공간별로 레이아웃을 선택하고 재료를 배치한 뒤 PDF로 출력하면 끝!

전체 흐름
1
재료 DB 세팅 — 자주 쓰는 재료를 카테고리별로 등록하고 예시이미지를 붙여두세요. 한 번만 하면 모든 프로젝트에서 써먹을 수 있어요.
2
프로젝트 생성 — 프로젝트 이름, 주소, 용도를 입력해서 새 프로젝트를 만들어요.
3
공간 추가 — 외벽, 지붕, 거실 등 공간을 만들고 맞는 레이아웃을 선택해요 (5가지 제공).
4
재료 배치 — DB에서 재료를 골라 바닥/벽/천정 슬롯에 배치하고, 스업/렌더링 이미지를 업로드해요.
5
PDF 출력 — 미리보기로 확인 후 A4 가로 형식으로 출력. 공간 1개당 1페이지로 자동 분리돼요.

프로젝트
공간을 만들고 재료를 배치. 이미지 업로드 후 PDF 출력.
지금은 새로고침하면 데이터가 사라져요. 곧 GitHub 자동 저장 기능이 추가될 예정이에요. 그 전까지는 중요한 작업 후 JSON 내보내기를 활용하세요.
재료 DB
재료 DB는 유타건축이 공통으로 사용하는 재료 라이브러리예요. 한 번 잘 세팅해두면 모든 프로젝트에서 가져다 쓸 수 있어요.
카테고리 관리
+
왼쪽 사이드바 하단 "+ 카테고리 추가" 클릭 → 이름 입력 → 새 카테고리 생성
+
참고 페이지 그룹도 같은 방식으로 추가 가능 (계단 참고, 창호 참고 등)
재료 추가
1
카테고리 선택 → 우측 하단 "재료 추가" 카드 클릭
2
재료명, 설명 입력 → 기본 등록
3
카드 위 "편집" 버튼 클릭 → 스펙 상세(SIZE/COLOR/단가/제조사), 예시이미지, 대안 재료 추가
예시 이미지
재료 카드 위에 마우스를 올리면 "이미지" 버튼이 나타나요. 최대 3장까지 업로드할 수 있어요.
예시이미지를 등록해두면 PDF 출력 시 해당 공간 하단에 "재료 예시 이미지" 섹션으로 자동 삽입돼요. 클라이언트에게 재료 느낌을 잘 전달할 수 있어요.
즐겨찾기
재료 카드 좌상단 ★ 버튼을 클릭하면 즐겨찾기 등록. 목록 상단에 고정되고, 재료 선택 팝업에서 "★ 즐겨찾기" 탭으로 빠르게 접근할 수 있어요.
대안 재료 연결
재료 편집 모달 하단에서 DB를 검색해 대안 재료를 연결할 수 있어요. 최대 5개까지 가능. 카드에 "↔ 재료명" 태그로 표시돼요.
예산 조정 시 "삼한C1 그레이토담 → 두라스택 베이직그레이" 같이 대안을 미리 연결해두면 클라이언트 상담 때 바로 제안할 수 있어요.
일괄 업로드
파일명 규칙에 맞게 저장한 이미지들을 한꺼번에 선택하면, 자동으로 카테고리 분류 + 재료 등록 + 이미지 세팅까지 해줘요.

업로드 순서
1

2
사이드바 "일괄 업로드" 클릭 → 업로드 영역 클릭 → 파일 선택 (Ctrl+A 전체 선택 가능)
3
분석 결과 확인 (새 재료 / 이미지 추가 / 오류 구분)
4
"DB에 등록" 클릭 → 완료!
템플릿
자주 쓰는 공간 조합을 저장해두고 새 프로젝트에 한 번에 적용할 수 있어요.
공통 템플릿 vs 프로젝트 템플릿
🌐
공통 템플릿
모든 프로젝트에서 사용 가능. "단독주택 기본 세트", "근린생활시설 외부" 등 공통 패턴.
📁
프로젝트 템플릿
특정 프로젝트에서 저장한 공간 조합. 비슷한 프로젝트 작업 시 재활용.
템플릿 저장
1
프로젝트 모드에서 "템플릿 저장" 클릭 (또는 템플릿 탭에서 직접 추가)
2
이름, 설명 입력 → 저장 위치 선택 (공통/프로젝트)
3
포함할 공간 체크 선택 → 재료 세팅까지 통째로 저장됨
템플릿 적용
1
프로젝트 선택 후 "템플릿 적용" 클릭
2
원하는 템플릿 선택 → 미리보기 확인
3
"적용" 클릭 → 공간들이 프로젝트에 추가됨
템플릿 탭의 카드에서 "적용" 버튼을 바로 눌러도 현재 선택된 프로젝트에 즉시 적용돼요.
프로젝트
새 프로젝트 만들기
1
프로젝트 탭 → 왼쪽 패널 하단 "+ 새 프로젝트" 클릭
2
프로젝트 이름(필수), 주소, 용도(복수 선택), 메모 입력
3
용도에 없는 항목은 "기타" 선택 후 직접 입력 가능
프로젝트 복사
프로젝트 목록에서 복사 버튼 클릭 → 공간/재료 세팅이 그대로 복사된 "(복사본)" 프로젝트 생성. 비슷한 프로젝트 빠르게 시작할 때 활용!
프로젝트 검색 & 필터
상단 검색창에서 프로젝트명, 주소, 용도, 메모로 검색 가능. 용도 칩(단독주택, 근린생활시설 등)을 클릭하면 해당 용도만 필터링돼요.
공간 추가
1
우측 상단 "공간 추가" 클릭 → 레이아웃 선택 (오른쪽 미리보기 확인)
2
공간 이름 입력 (예: 외벽, 1F 거실, 필로티 주차장)
3
바닥/벽/천정 슬롯에서 "추가" 클릭 → DB에서 재료 선택
4
대표 이미지(스업/렌더링) + 상세 이미지 최대 3장 업로드
5
필요하면 "참고 페이지 연결"로 계단 구조 등 참고 자료 연결
재료는 DB 카테고리 상관없이 어느 공간, 어느 슬롯에도 자유롭게 배치할 수 있어요. 예를 들어 벽돌을 외벽 벽에도, 계단 바닥 디딤판에도 쓸 수 있어요.
레이아웃 5종
공간을 추가할 때 페이지 레이아웃을 선택해요. 공간의 성격에 맞는 레이아웃을 고르면 돼요. 레이아웃 선택 시 오른쪽에 실제 미리보기가 표시돼요.
A — 재료 이미지형
바닥/벽/천정 재료 슬롯 + 스업 이미지 + 상세 이미지 3장. 가장 기본적인 레이아웃.
→ 외벽, 실내 각 공간, 주차장 단일 부위
B — 텍스트 스펙형
TYPE/SIZE/COLOR 등 텍스트 스펙을 직접 입력. 여러 항목 블록을 추가할 수 있어요.
→ 지붕, 난간, 창호, 후레싱
C — 다중 항목형
한 공간 안에 A/B/C로 부위를 구분. 각각 바닥/벽/천정 슬롯과 이미지 별도 관리.
→ 필로티 주차장, 외부계단, 실내계단
D — 비교 선택형
여러 옵션을 이미지 카드로 나열하고 선택 표시. 클릭으로 선택/해제.
→ 계단 구조/마감/난간 참고, 창호 타입 비교
E — 표 형식형
구분/업체명/모델명/규격/비고 등 열을 행 단위로 정리. 행 추가/삭제 가능.
→ 조명 목록, 창호 비교표, 스위치 사양표
레이아웃은 공간 추가 후에도 변경할 수 있지만, 기존에 입력한 재료/스펙 데이터는 초기화될 수 있어요. 처음부터 맞는 레이아웃을 선택하는 게 좋아요.
PDF 출력
A4 가로(landscape) 형식으로 출력돼요. 공간 1개 = 페이지 1장으로 자동 분리돼요.
미리보기
1
프로젝트 모드에서 상단 "미리보기" 버튼 클릭
2
프로젝트명, 날짜, 로고, 푸터 문구를 직접 클릭해서 수정 가능
3
수정 완료 후 "인쇄/PDF" 버튼으로 출력
PDF 저장 방법
1
인쇄 창이 열리면 프린터 목록에서 "PDF로 저장" 또는 "Microsoft Print to PDF" 선택
2
용지 크기: A4, 방향: 가로(Landscape) 확인
3
저장 위치 지정 후 저장
PDF 페이지 구성
각 페이지는 다음 순서로 구성돼요:
①
헤더 — 프로젝트명, 날짜/용도/주소, 유타건축
②
공간명 — 대문자로 표시
③
좌측 — 바닥/벽/천정 재료 (이미지 + 이름 + 카테고리)
④
우측 — 스업/렌더링 대표 이미지 + 상세 이미지 3장
⑤
하단 — 재료 예시 이미지 (DB에 등록된 경우) + 참고 페이지 카드
재료 DB에 예시이미지를 미리 등록해두면 별도 작업 없이 PDF 하단에 자동으로 삽입돼요!
팁 & FAQ
Q. 새로고침하면 데이터가 사라져요
현재는 브라우저 메모리에만 저장돼요. GitHub 저장 기능이 추가될 예정이에요. 그 전까지는 작업이 끝나면 바로 PDF로 저장해두세요.
Q. 재료를 여러 공간에 같이 쓸 수 있나요?
네! DB에서 한 번 등록한 재료는 어느 공간, 어느 슬롯에도 자유롭게 배치할 수 있어요. 예를 들어 벽돌을 외벽 벽에도, 계단 디딤판에도 쓸 수 있어요.
Q. 용도 목록에 원하는 용도가 없어요
새 프로젝트 생성 시 "기타"를 선택하면 직접 입력 필드가 나타나요. 자유롭게 입력할 수 있어요.
Q. 비슷한 프로젝트를 빠르게 만들고 싶어요
두 가지 방법이 있어요. ① 프로젝트 목록에서 복사 버튼으로 프로젝트 전체 복사. ② 자주 쓰는 공간 조합을 템플릿으로 저장 후 새 프로젝트에 적용.
Q. 이미지 업로드 시 파일명 규칙을 꼭 따라야 하나요?
일괄 업로드 기능을 쓸 때만 필요해요. 개별 재료 카드에서 직접 업로드할 때는 규칙 없이 자유롭게 올릴 수 있어요.
Q. 참고 페이지는 어디에 쓰나요?
계단 구조/마감/난간처럼 모든 프로젝트에 공통으로 보여주는 예시 이미지 모음이에요. DB 메뉴 > 참고 페이지에서 그룹별로 카드를 만들어두면, 공간에 연결해서 PDF에 자동 삽입돼요.
Q. 사용법 페이지는 최신 상태인가요?
기능이 추가/수정/삭제될 때마다 이 가이드도 함께 업데이트돼요. 언제든 이 버튼을 눌러 확인하세요.
기능 추가 요청이나 사용법 개선이 필요하면 슬기에게 얘기해주세요!
